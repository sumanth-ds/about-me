Interactive Setup Guide

Follow this step-by-step guide to get the code editor running locally

Check Your Tools

Ensure you have the following installed:

  • Python 3.8+
  • Node.js (for JS execution)
  • Java Development Kit (JDK)

Configure the Backend

Install the required Python packages:

pip install Flask Flask-Cors requests
Copied!

Set your Gemini API key in app.py, then run:

python app.py
Copied!

Launch the Frontend

With the backend server running, simply open the index.html file in your browser.

You're all set!

Frequently Asked Questions

Common issues and solutions for the AI Code Editor

"Error: Could not connect to the backend."

  • Ensure your Flask backend (app.py) is running in your terminal.
  • Verify that the BACKEND_URL in index.html matches the address Flask is running on.
  • Check for firewall issues that might be blocking the connection.

    • "Interpreter not found."

  • Make sure Python, Node.js, and the Java JDK are correctly installed and added to your system's PATH.

    • Why are there no AI suggestions?

  • Verify your Gemini API_KEY in app.py is correct and active.
  • Check your internet connection, as the app needs to reach Google's servers.
  • Review the Flask backend console for any API-related error messages.
