Intelligent Document Interaction Platform

A sophisticated Streamlit-based conversational AI platform featuring Retrieval-Augmented Generation (RAG) for enhanced data interaction. Chat with CSV, PDF, and web URLs using Google Gemini and Meta Llama.

Core Capabilities:

  • Chat with CSV: Query structured data with natural language
  • Chat with PDF: Extract and analyze document content
  • Chat with URL: Retrieve and process web page information

Interactive Setup Guide

Follow this step-by-step guide to get the chatbot running locally

Check Your Tools

Ensure you have Python installed and API keys for the required services.

  • Python 3.8 or newer
  • Active Google Cloud API Key
  • Active Together AI API Key

Install Dependencies

Run the following command to install all necessary Python packages:

pip install streamlit langchain-experimental langchain-core langchain-google-genai langchain-community langchain-text-splitters requests beautifulsoup4 python-dotenv langchain-together
Copied!

Configure API Keys & Run Server

Create a folder named .streamlit and a secrets.toml file inside it:

# .streamlit/secrets.toml
google = "YOUR_GOOGLE_API_KEY_HERE"
together = "YOUR_TOGETHER_API_KEY_HERE"
Copied!

Run the Streamlit application:

streamlit run app.py
Copied!
